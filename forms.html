Introduction to forms

Forms

In PHP, forms are essential for interacting with users and collecting data. They allow users to input information, which can then be processed by a PHP script.
We can create and use forms in PHP. To get form data, we need to use PHP superglobals $_GET and $_POST.

The form request may be get or post. To retrieve data from get request, we need to use $_GET, for post request $_POST.
The HTML <form> tag is used to create a form.The syntax of <form> tag is:

Syntax:

                <form action="script url" method="GET/POST">
                     form elements
                </form>

Forms Attributes

In HTML, the <form> tag has several attributes that help define how the form data will be handled. Two of the most essential attributes are action and method.
Action: The action attribute specifies where the form data should be sent once the user submits it. It usually contains a URL pointing to a PHP script or a server-side resource that will process the form data.
Method: The method attribute specifies how the form data should be sent to the server. There are two main methods: GET and POST.
GET:
->Data is sent as URL parameters, visible in the browser address bar.
->Form data is appended to the URL as a query string.
->The size of the data is limited by the URL length (generally around 2048 characters).
->Use GET for non-sensitive data like search queries or simple data retrieval.

Syntax:

        
        <form action="search.php" method="get">
            <label for="query">Search:</label>
            <input type="text" id="query" name="query">
            <input type="submit" value="Search">
        </form>
POST:
->Data is sent as part of the HTTP request body, making it invisible in the browser’s address bar.
->There’s no size limitation for the form data (although server configurations may impose limits).
-> More secure than GET and suitable for sending sensitive data like passwords, files, and personal information.

Syntax:

                    <form action="search.php" method="post">
                        <label for="query">Search:</label>
                        <input type="text" id="query" name="query">
                        <input type="submit" value="Search">
                    </form>

    Super Global Variables

    Superglobal Variable Definition
    $_GLOBALS This superglobal is used to access global variables from anywhere in the PHP script, including functions and methods. It contains all the global variables.
    $_SERVER Contains information about headers, paths, and script locations. It provides details about the server and execution environment (e.g., server name, request method, IP address, etc.).
    $_GET An associative array that contains data sent through a URL using the HTTP GET method. It’s used to collect form data from a URL or query string.
    $_POST An associative array that contains data sent through an HTTP POST method. It’s used to collect data securely from a form that is not visible in the URL.
    $_FILES Contains information about uploaded files, including details like file name, size, temporary name, and error status. It's used to handle file uploads.
    $_COOKIE An associative array that contains data from cookies sent by the browser. It’s used to retrieve values stored in cookies on the client-side.
    $_SESSION Used to store and retrieve session variables, which are stored on the server and persist across multiple pages during a user's visit.
    $_REQUEST An associative array that contains data from $_GET, $_POST, and $_COOKIE combined. It can be used to collect data from different sources.
    $_ENV Contains environment variables passed to the PHP script. It is often used to access server configuration or environment information.
